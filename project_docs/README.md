# OpenXComZX — проектная документация

Цель проекта: порт (сильно адаптированный) OpenXcom / X-COM: UFO Defense на
платформу **TS-Config** (ZX-Evolution / Pentevo, Z80 до 14 МГц, 4 МБ
страничной памяти, аппаратные тайлы/спрайты/DMA) с опциональной поддержкой
платы **OPL3** (YMF262) для музыки и звука.
