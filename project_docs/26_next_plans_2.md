## 3. Сохранение и загрузка посреди боя, Ironman в бою

**Оригинал:** `SavedBattleGame::save/load` (`:386-479`), тайлы по 23 байта, юниты, предметы, узлы;
сторона хода не сохраняется (при загрузке — X-COM); окна сохранения в теме боя
(`applyBattlescapeTheme`, `State.cpp:405-428`); Ironman — автосохранение на ходе 1 и каждом 5-м
(`NextTurnState.cpp:186-190`), «Save and abandon».

**Схема:** файл слота = блок кампании (`st_save`, как сейчас) + боевая часть: заголовок `bsv_hdr_t`
(~230 Б: миссия, наборы, `used[32]`, ход, сторона, выбор, счётчики, листы пришельцев, таблица
разделов) и разделы с границ 512 Б: CELLS (`G.page`, sx·sy·sz·4), FOG, UNITS (`unit_t[40]`), ITEMS,
NODES (`G.npage`), UFOOPEN. Всё выводимое из правил (таблицы частей, тайлсеты, листы, маска обзора,
руки, пули) — пересобирается. **`used[32]` с момента генерации обязательна**: `tiles_load` раздаёт
номера частям дверей НЛО в обход маски, пересчёт по текущим клеткам «сдвинет» части (`TV_USED 10080`).
Объём: ~62 КБ на поле 50×50×4 + ~37 КБ кампании. Сохранять только на ходу X-COM в покое (отличие от
оригинала — записать в 16 §6.5).
**Ввод-вывод:** служба BIOS — запись/чтение по смещению (команды 5, 6; блок запроса на стек — Win1
освобождает 12 Б), `bios.c` → банк 41 (#0D). Позже — слоты-файлы на SD фиксированного размера.
**Загрузка:** `st_load` → `kind == 1` → проверка → `bsv_resume` → геоскейп → `ui_request = SCR_BATTLE` →
`EVT_OPEN` боя ветвит `resume()`; `mapgen_adopt`, `bat_load` с `restore`, листы пришельцев в
сохранённом порядке, `vis_build` + туман, предметы и `bi_restore`, двери НЛО, сумма.
**Окна в теме боя:** `bat_theme()` в `scr_menu.c`; кнопка Save в паузе боя; Ironman — без Load/Save,
«Save and abandon». `A_POPN 3` после сохранения (меняет `ui_geoscape`/`campaign` — отдельным шагом).
**Этапы:** 1 BIOS со смещением → 2 подготовка (структура `bc`, `TV_USED`, аксессоры, разбиение
`load_gen`) → 3 сохранение → 4 загрузка (`bat_save.oxs`) → 5 тема окон → 6 Ironman (`bat_iron.oxs`) →
7 SD-слоты → 8 RLE и быстрая загрузка из боя.
**Риски:** нумерация частей дверей НЛО, необнулённая память банков, банк 31 и Win1 почти полны,
длина BIOS u16, `fat_write` — только целые секторы, медленная загрузка из боя (перечитывание GEO.PAK),
без SD-слотов на железе сохранение боя не работает до этапа 7.

- Win1: `_DATA` до `#7BFC` при пределе `#7C00` — 4 байта.
