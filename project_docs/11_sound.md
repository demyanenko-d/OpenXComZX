# Звук: режимы музыки и эффектов

Решение пользователя (2026-09-14): **режим звука выбирается в настройках
игры** (своё окно опций). Нужны варианты:

| # | Музыка | Эффекты (SFX) | Железо |
|---|---|---|---|
| 1 | OPL3 | AY-3-8910 (один чип) | плата OPL3 (MoonSound) + AY |
| 2 | AY | тот же AY — эффект временно забирает канал(ы) у музыки | один AY |
| 3 | AY №1 | AY №2 | TurboSound (2 x AY) |
| 4 | FM-части двух YM2203 | PSG-части (SSG) двух YM2203 | TurboSound FM (2 x YM2203) |

Плюс «без звука». Позже, по возможности: эффекты на свободных каналах OPL3
(банк 1, каналы 3–8) и волновая часть OPL4, если плата MoonSound с памятью.

## Что это значит для конвертера

Музыка оригинала — `ADLIB.CAT` (12 голосов FM, 2-операторные патчи OPL2).
Для каждого режима конвертер готовит свой **покадровый поток** (48.83 Гц,
как для OPL3 — 09 §7), чтобы на Z80 не было синтеза — только вывод регистров:

- **OPL3** — сделано (`MUSIC.PAK`).
- **AY (3 канала)** — сведение 12 FM-голосов к 3 каналам меандра + шум:
  выбор голосов по приоритету (бас, мелодия, ударные/огибающие), частоты AY
  по нотам, громкость из уровня оператора-несущей, шумовой канал для
  ударных инструментов. Для режима 2 — отдельная версия с «зарезервированным»
  каналом под эффекты (или приоритет эффекта над голосом).
- **YM2203 FM (2 x 3 FM-канала)** — перенос 2-оп. патчей OPL2 на 4-оп. OPN
  (алгоритм с двумя активными операторами), до 6 FM-голосов; SSG-части
  остаются эффектам.
- **Эффекты** — оригинал хранит сэмплы (`SOUND/SAMPLE*.CAT`, `SOUND1/2.CAT`).
  Для AY/SSG: автоматическое преобразование сэмпла в покадровую огибающую
  (громкость = RMS за кадр, тон/шум — по спектру/переходам через ноль) →
  короткий поток регистров AY на канал. Таблица эффектов — по номерам звуков
  OpenXcom (`GEO.CAT`/`BATTLE.CAT`: кнопка, окно, выстрелы, взрывы…).

## Что это значит для движка

- «Звуковой драйвер» в BIOS игры (страница ядра): в кадровом прерывании
  выводит поток музыки выбранного режима и активные эффекты; единый API
  «играть музыку N / эффект M».
- Порты: OPL3 #C4–#C7 (02 §7), AY/TurboSound #FFFD/#BFFD с выбором чипа,
  YM2203 FM через те же порты (режим TurboSound FM). Полярность выбора чипа и
  разрешение FM — проверить на железе (02 §12, противоречия в источниках).
- Определение наличия плат при старте (OPL3 — тест таймеров; TurboSound FM —
  чтение статуса YM2203) и предложение режима по умолчанию.

## Статус

Режим 1 (музыка): поток OPL3 готов. Остальное — план (следующие шаги
конвертера после правил).
